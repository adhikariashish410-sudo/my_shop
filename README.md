 Description
MyShop is a multi-screen mini e-commerce application built using Flutter. It displays static product data organized across different categories. Users can navigate from a welcome page to a main shopping dashboard, view category-filtered product listings, and inspect individual product details with interactive feedback.

---

 Key Features
* **Welcome Screen:** Engaging onboarding screen with smooth navigation.
* **Promotional Carousel Banner:** Implemented using the `carousel_slider` package from pub.dev.
* **Horizontal Category Selection:** Scrollable category tags to quickly filter items.
* **Reusable Product Cards:** Clean card architecture built using `Card`, `Container`, and `Stack` layout widgets.
* **Category Page:** Displays products in a responsive `GridView.builder` layout.
* **Product Details Screen:** Shows item images, ratings, descriptions, pricing, and an interactive "Add to Cart" button that triggers a `SnackBar`.
